# Antivirus vs Virus Cluster

Interaktīva 2D *top-down* šaušanas spēle (*arcade shooter*), kas izstrādāta HTML5 Canvas un JavaScript vidē. Spēlētājs vada antivīrusa programmu, kuras uzdevums ir attīrīt datorsistēmu no dažādu tipu vīrusu draudiem 12 līmeņu garumā.

## 🚀 Spēlēt Tiešsaistē (Live Demo)
Spēle ir pilnībā gatava un spēlējama pārlūkprogrammā:
👉 **[Spēlēt Antivirus vs Virus Cluster](https://krissap.github.io/Anti_virus_game/)**

---

## 🎮 Vadība (Controls)
* **W / A / S / D** — Pārvietošana
* **Peles kustība** — Tēmēšana
* **Peles kreisais taustiņš** — Šaušana / Attīrīšana

---

## 🛠️ Galvenās Funkcijas
* **12 Progresīvi Līmeņi:** Pieaugoša grūtības pakāpe un pretinieku viļņi.
* **3 Unikālas Bosa Fāzes:** Cīņas ar Error logiem, inficēto failu klasteriem un migrācijas matrices lāzeriem.
* **Modulārie Uzlabojumi:** Iespēja izvēlēties uzlabojumus (*Spread Scanner*, *High-Frequency Fire*, *Shield Reinforce*).
* **Veselības Atjaunošana:** `+HP` kapsulas, kas palīdz noturēties cīņā.
* **Rezultātu Tīrklājs:** Lokālais *Leaderboard* labāko punktu saglabāšanai.
